## Overview

MySSICalendar is a simple web tool that helps people quickly check upcoming SSI, SSDI, and Social Security payment dates.

Most payment schedules are buried in tables or PDFs that aren’t easy to read or interpret. This tool puts everything into one clean dashboard so users can see what they need instantly.

## Project Summary

Most Social Security payment schedules are buried in tables or PDFs that aren’t easy to read or interpret.

I built this to simplify that — instead of figuring it out manually, the app shows the next payment date instantly and calculates how far away it is.

This reflects how I approach problems: simplify the experience, structure the logic, and build something people can actually use.

---

## Key Logic Highlight

- Dynamic “days away” calculation based on today's date  
- Handles early payments when the 1st falls on weekends or holidays  
- Tab-based switching for SSI, SSDI, Retirement, and Survivor benefits  

---

## Features

- View next payment date instantly  
- Dynamic countdown (“days away”)  
- Switch between benefit types  
- 2026 calendar view  
- Mobile-friendly layout  
- Print and utility tools  

---

## Why I Built This

A lot of people rely on Social Security payments but don’t have an easy way to understand when money is actually coming.

This was a straightforward problem to solve, so I built a cleaner version of it.
